Tactic: TA0006 Credential_Access
Technique: T1110.001 Brute_Force_Password_Guessing

Background
Given process as AuthenticationService
And account as TargetAccount
And message as CorrectCredentials
And message as IncorrectCredentials
And session as User

Event 1
Given AuthenticationService is awaiting_input

Then IncorrectCredentials is rejected
Repeated 5 times within 1 sec

Event 2

And User is active
