Tactic: TA0007 Stamatia
Technique: T0803 Something_Random

Background
Given laptop as stama
And mouse as clickity
And screen as light
And human as student
And click as click

Event 1
Given stama is active
When student uses clickity
Then clickity is clicked

Event 2
Given clickity is clicked
When stama receives click
Then click is received
And stama is modified

Event 3
Given stama is modified
When stama commands light 
Then light is active

Event 4
Given light is active
When student hides light
Then light is inactive

Event 5
Given light is active
When student uses stama
Then light is modified

Detection
Event 4 Or Event 5
