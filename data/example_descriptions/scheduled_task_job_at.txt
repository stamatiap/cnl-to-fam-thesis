Tactics: TA0002 Execution, TA0003 Persistence, TA0004 Privilege_Escalation
Technique: T1053.002 Scheduled_Task_Job_At

Background
Given process as at_exe with command_line = "at.exe"
And process as WMI_Win32_ScheduledJob
And process as AnomalousScheduledTask
And process as svchost_exe with command_line = "svchost.exe"
And process as taskeng_exe with command_line = "taskeng.exe"

Event 1
Given WMI_Win32_ScheduledJob is activated
When WMI_Win32_ScheduledJob creates AnomalousScheduledTask
Then AnomalousScheduledTask is created

Event 2
Given at_exe is activated
When at_exe creates AnomalousScheduledTask
Then AnomalousScheduledTask is created

Event 3
Given AnomalousScheduledTask is created And svchost_exe is activated
When svchost_exe executes AnomalousScheduledTask
Then AnomalousScheduledTask is activated

Event 4
Given AnomalousScheduledTask is created And taskeng_exe is activated
When taskeng_exe executes AnomalousScheduledTask
Then AnomalousScheduledTask is activated

Completion
Event 3 Xor Event 4
