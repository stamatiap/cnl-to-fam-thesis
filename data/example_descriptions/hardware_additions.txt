Tactics: TA0001 Initial_Access
Technique: T1200 Hardware_Additions

Background
Given operating_system as Windows
And device as USB_device
And device as Thunderbolt_device
And device as PCIe_device
And device as BD
And user as User
And process as P1
And volume as V
And input as HID_keystroke
And driver as DMA_driver
And server as DHCP
And interface as MAC

Event 1
Given Windows is active And User is active
When Windows recognizes USB_device
Then USB_device is active

Event 2
Given Windows is active And User is active
When Windows recognizes Thunderbolt_device
Then Thunderbolt_device is active

Event 3
Given Windows is active And User is active
When Windows recognizes PCIe_device
Then PCIe_device is active

Event 4
Given Windows is active
When Windows recognizes BD
Then BD is active

Event 5
Given USB_device is active Xor Thunderbolt_device is active Xor PCIe_device is active Xor BD is active
When User spawns P1
Then P1 is active

Event 6
Given USB_device is active Xor Thunderbolt_device is active Xor PCIe_device is active Xor BD is active
When Windows mounts V
Then V is mounted

Event 7
Given P1 is active Xor V is mounted
When Windows receives HID_keystroke
Then HID_keystroke is received

Event 8
Given P1 is active Xor V is mounted
When Windows loads DMA_driver
Then DMA_driver is loaded

Event 9
Given P1 is active Xor V is mounted
When DHCP receives MAC
Then MAC is received

Detection
Event 7 Xor Event 8 Xor Event 9
