Tactic: TA0006 Credential_Access
Technique: T1003.001 OS_Credential_Dumping_LSASS

Background
Given process as P
And operating_system as OS
And file as lsass_exe
And file as lsass_dump
And registry as registry_keys
And handle as handle_request

Event 1
Given P is active
When P requests handle_request to lsass_exe from OS
Then P has_access to lsass_exe 

Event 2
Given P has_access to lsass_exe 
When P loads lsass_exe
Then lsass_exe is active

Event 3
Given lsass_exe is active
When P requests lsass_dump from lsass_exe
Then lsass_dump exists

Event 4
Given lsass_dump exists
When P modifies registry_keys
Then registry_keys is modified

Detection
Event 3 Xor Event 4
