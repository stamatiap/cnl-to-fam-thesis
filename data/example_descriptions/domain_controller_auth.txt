Tactics: TA0003 Persistence
Technique: T1556.001 Modify_Authentication_Process_Domain_Controller_Authentication 

Background
Given server as domain_controller
And process as lsass_exe
And process as unusual_privileged_process
And file as authentication_DLL
And registry as registry_keys
And user as User

Event 1
Given unusual_privileged_process is active in domain_controller
When unusual_privileged_process loads authentication_DLL
Then authentication_DLL is active And unusual_privileged_process is active in domain_controller

Event 2
Given unusual_privileged_process is active in domain_controller
When unusual_privileged_process accesses lsass_exe
Then lsass_exe is accessed by unusual_privileged_process And unusual_privileged_process is active in domain_controller

Event 3
Given lsass_exe is accessed by unusual_privileged_process And unusual_privileged_process is active in domain_controller
When unusual_privileged_process modifies registry_keys
Then registry_keys is modified


Completion
Event 1 And Event 2 And Event 3
