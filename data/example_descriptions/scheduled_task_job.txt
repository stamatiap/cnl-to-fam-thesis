Tactics: TA0002 Execution
Technique: T1053 Scheduled_Task_Job

Background
Given process as schtasks_exe
And process as at_exe
And process as COMobjects
And process as ScheduledTask
And user as User
And process as OutlierProcess

Event 1
Given schtasks_exe is active Xor at_exe is active Xor COMobjects is active
When User modifies ScheduledTask
Then ScheduledTask is modified

Event 2
Given schtasks_exe is active Xor at_exe is active Xor COMobjects is active
When User creates ScheduledTask
Then ScheduledTask is created

Event 3
Given ScheduledTask is modified Xor ScheduledTask is created
When ScheduledTask executes OutlierProcess
Then OutlierProcess is active

Detection
Event 3
