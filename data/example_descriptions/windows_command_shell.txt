Tactic: TA0002 Execution
Technique: T1059.003 Windows_Command_Shell

Background
Given process as P
And process as cmd_exe
And script as batch_script
And file as remote_file
And file as local_file
And network_connection as connection

Event 1
Given P is active
When P spawns new cmd_exe
Then cmd_exe is spawned by P

Event 2
Given Event 1
When cmd_exe executes batch_script
Then batch_script is executed by cmd_exe

Event 3
Given Event 1
When cmd_exe requests remote_file from connection
Then remote_file is requested by cmd_exe

Event 4
Given Event 3
When cmd_exe executes remote_file
Then remote_file is executed by cmd_exe

Event 5
Given Event 1
When cmd_exe creates new local_file
Then local_file is created by cmd_exe

Event 6
Given Event 5
When cmd_exe executes local_file
Then local_file is executed by cmd_exe

Detection
Event 2 Or Event 4 Or Event 6
