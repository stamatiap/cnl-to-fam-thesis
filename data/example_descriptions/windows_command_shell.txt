Tactics: TA0002 Execution
Technique: T1059.003 Command_and_Scripting_Interpreter_Windows_Command_Shell

Background
Given process as unusual_process
And process as cmd_exe
And file as batch_file
And process as shell
And message as cmd_parameters

Event 1
Given unusual_process is active
When unusual_process spawns cmd_exe
Then cmd_exe is active And unusual_process is active

Event 2
Given cmd_exe is active And batch_file exists
When cmd_exe executes batch_file
Then batch_file is executed

Event 3
Given unusual_process is active
When unusual_process spawns shell
Then shell is active And unusual_process is active

Event 4
Given shell is active And batch_file exists
When shell executes batch_file
Then batch_file is executed

Completion
Event 2 Xor Event 4
