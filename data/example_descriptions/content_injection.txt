Tactic: TA0001 Initial_Access
Technique: T1659 Content_Injection

Background
Given browser as B
And folder as AppData
And folder as Temp
And process as P
And file as F1
And file as F2

Event 1
Given B is active
When B spawns new P
Then P is spawned

Event 2
Given Event 1
When P creates new F1 in AppData
Then F1 is created in AppData

Event 3
Given Event 1
When P creates new F2 in Temp
Then F2 is created in Temp

Event 4
Given Event 2
When P executes F1
Then F1 is executed by P

Event 5
Given Event 3
When P executes F2
Then F2 is executed by P

Detection
Event 4 Or Event 5
